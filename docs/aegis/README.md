# Aegis Design Workspace

This directory records durable requirements, architecture decisions, and design evidence for changes that need more than an implementation-only pull request.

- `baseline/` captures the repository state used by later design checks.
- `specs/` contains reviewed feature contracts.
- `adr/` is reserved for accepted architecture decisions when a change creates a durable owner or public contract.

Repository documentation and tests remain authoritative for current behaviour. These records explain intended changes before implementation.
